1. What to copy (the “shape” of the job)

Option Meaning When it’s interesting
/S Subfolders, not empty ones Slightly lighter than /E if empty dirs don’t matter
/E Subfolders including empty Default in the app — full tree shape
/LEV:n Only the first n levels “Copy only top 2 levels of this huge tree”
/MIR Mirror = /E + /PURGE Make dest identical to source (can delete extras on dest)
/PURGE Delete dest files that vanished from source Cleanup without full mirror packaging
/MOV / /MOVE Copy then delete from source True “move” of files / whole tree
/CREATE Create tree + 0-byte files only Pre-create structure / test paths without data
Takeaway: /E + /XO = update. Add /PURGE to also delete dest-only files while keeping /XO. /MIR = make dest a clone (dangerous if paths are wrong). Always dry-run (/L) before /PURGE or /MIR.

2. What “same file” means (selection filters)

These control which files Robocopy decides to copy — this is where it beats Explorer.

Option Meaning Why it’s useful
/XO Exclude Older (skip if dest is newer / same under Robocopy’s rules) Daily “update folder” mode
/XN Exclude New (don’t add files that only exist on source) Refresh existing files only
/XC Exclude Changed Rare; narrow jobs
/XX Don’t report/copy “extra” on dest Quieter logs; no interest in dest-only files
/XL Exclude “Lonely” (exist only on one side) Only touch files present on both sides
/IS Include Same files Force re-copy even when Robocopy thinks identical
/IT Include “Tweaked” Subtle attribute/time edge cases
/IM Include Modified (different modify times) When “same size” but different mtime should still copy
/FFT FAT-style times (2-second granularity) Cross-drive / USB / NAS time noise
/DST Compensate 1-hour DST shifts Seasonal “everything looks 1h off” nonsense

Age / size filters (very handy)

Option Effect
/MAX:n / /MIN:n Max/min file size (bytes)
/MAXAGE:n / /MINAGE:n Only files older/newer than n days (or a date)
/MAXLAD / /MINLAD By last access time

Example idea: copy only files modified in the last 7 days:

robocopy SRC DST /E /MAXAGE:7

3. Exclude noise (huge quality-of-life)

Option Meaning
/XF file… Exclude files by name/wildcard (*.tmp, Thumbs.db, …)
/XD dir… Exclude folders (node_modules, .git, $RECYCLE.BIN, …)
/XA:… Exclude by attributes (e.g. hidden/system)
/IA:… Include only certain attributes
/A / /M Only files with Archive bit (/M clears it after — classic backup style)

Example: update a project tree without dependencies:

robocopy C:\proj D:\backup\proj /E /XO /XD node_modules .git __pycache__ /XF *.log

This is often more valuable than raw speed.

4. Performance & network

Option Meaning Notes
/MT[:n] Multi-thread (default 8, max 128) Great for many small files; already in the app
/J Unbuffered I/O Often better for very large files
/IPG:n Inter-packet gap (ms) Throttle on slow/WAN links (incompatible with /MT)
/IoRate:… / /IoMaxSize:… I/O rate limiting Protect a live server disk from being saturated
/COMPRESS Request SMB compression Can help on some networks
/Z Restartable mode Resume large interrupted network copies
/B / /ZB Backup mode / restart→backup Needs privileges; helps locked/special files
/RH:hhmm-hhmm Only run in a time window Night-only jobs
/MON:n / /MOT:m Watch source and re-run after changes Continuous sync-ish behaviour
Default retries are brutal (/R ~ 1 million, /W 30s). Explorer Advance’s /R:1 /W:1 is intentional: fail fast on locked files.

5. Security & metadata (beyond “just the bytes”)

Option Copies…
/COPY:DAT Data, Attributes, Timestamps (default)
/SEC or /COPY:DATS + NTFS ACLs
/COPYALL Data + attrs + times + security + owner + auditing
/SECFIX Fix security on skipped files too
/TIMFIX Fix timestamps on skipped files
/DCOPY:… What to copy for directories
/EFSRAW Encrypted (EFS) files in raw form
/SL / /SJ Copy symlinks/junctions as links, not as targets
/XJ / /XJD / /XJF Exclude junctions/symlinks (avoids wandering into other volumes)

Interesting for “real” backups of NTFS shares: /COPYALL /DCOPY:DAT /MIR (with care), and /XJD so a junction doesn’t pull half the disk into the job.

6. Logging & dry-run (operations)

Option Role
/L List only — no copy/delete (best friend of /MIR). Explorer Advance Compare only uses this with no /XO and a compare_*.log for visual differences without copying.
/V Verbose (shows skipped files)
/TS / /FP Source timestamps / full paths in output
/ETA Estimated time of arrival per file
/NP No % progress (cleaner logs — used by the app)
/NDL / /NFL Suppress dir/file name lists
/LOG: / /LOG+: Overwrite vs append log
/UNILOG: Unicode log (better for non-ASCII names)
/TEE Console + log together
Exit codes: Robocopy treats 0–7 as often “OK”; ≥ 8 means real failure. An exit code of 1 after a real update is normal and good.

7. Jobs & automation

Option Role
/SAVE:jobname Save this command line as a job file
/JOB:jobname Reload and run a saved job
/QUIT Parse/show params and exit (debug)

Nice for recurring “Documents → NAS” recipes without retyping flags.

8. What maps well to common use cases

Goal Strong combo
Routine folder update /E /XO /FFT /R:1 /W:1 /MT:8 /LOG:… /TEE — basically what the app does
Preview first Add /L (and maybe /V)
Exact clone of source /MIR + dry-run first; optional /XJD
Backup with permissions /E /COPYALL /DCOPY:DAT /R:2 /W:5
Skip junk /XD + /XF
Only recent work /E /MAXAGE:7 (or 30)
Huge media files over LAN /E /XO /J /Z /MT:4 (tune threads; try /COMPRESS)
Don’t hammer a server /IPG or /IoRate instead of high /MT
Nightly auto sync /MIR + /RH:2200-0600 or Task Scheduler + the app’s command

9. Already in Explorer Advance vs nice future toggles

In the app today

/E, /XO, /FFT, /R, /W, /MT, /L, /MIR, /PURGE, /XJD, /SEC, /COPYALL, /DST, /J, /Z, /XD, /XF, /MAXAGE, /LOG, /TEE, plus /NP /NDL for cleaner live output. Named projects store the rows and these options.

Especially interesting to add later

  • /MINAGE and size filters — finer “only these files”
  • /DCOPY — directory timestamps
  • /EFSRAW — copy encrypted files as-is
  • /V / /ETA — richer logs
  • /LOG+ — append history instead of overwrite

Bottom line

Robocopy’s power isn’t only speed — it’s precise selection (/XO, age/size, /XF//XD), safe rehearsal (/L), controlled destruction (/PURGE//MIR), and metadata-aware copies (/COPY, /SEC). Explorer doesn’t give you that control.

Tip: from a terminal, robocopy /? shows the full official list for your Windows version (wording may be in the system language).
